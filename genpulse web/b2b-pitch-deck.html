The gap

Health AI lacks a household-scale phenotypic data layer.

  • Fragmented capture — episodic clinic visits and consumer apps, not continuous professional imaging at home.
  • No vertical phenotypes — scalp, skin, oral, and eye signals stay siloed; models train on proxies, not ground truth.
  • Slow validation loops — without governed memory, bad labels compound; datasets rot before they reach production models.
  • Distribution gap — strong foundation models exist, but few APIs trained on verified, longitudinal household phenotypic streams.

Memory architecture

Three-layer health memory — fast validate, clean, compound.

Analogous to production agent memory (episodic · semantic · state) and health vault APIs — optimized for phenotypic imaging, not chat logs.

Layer 1

Episodic · raw capture stream

Append-only, time-indexed device events: images, spectra, session metadata, device calibration. Immutable audit trail per household.

Layer 2

Semantic · validated phenotypes

Governed annotations per vertical spec (e.g. follicle type, lesion class, plaque index). Human-in-the-loop + model pre-label → QC → gold labels only.

Layer 3

State · model-ready memory

Longitudinal profiles, derived features, API-ready JSON. Authoritative "current health state" for agents, apps, and training exporters.
